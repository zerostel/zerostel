# Code of conduct

Zerostel follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be kind, assume good intent, and keep criticism about the work, not the person.

It applies in issues, pull requests, discussions and anywhere else you represent the project.

To report a problem, email hello@zerostel.com. Reports are read only by the maintainers and kept confidential.
