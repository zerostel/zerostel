Privacy

Zerostel collects nothing. It runs on your computer, keeps what it records there, and sends nothing anywhere.

Last changed 8 October 2026

The program

This covers Zerostel however you install it: the npm package, the executables, the Claude Code plugin, the other agents' plugins and extensions, the MCP server and the GitHub Action.

  • What it records. Your coding agents' sessions: your prompts, their tool calls and commands, the end of each command's output with the secrets it recognizes masked, which files changed, time and token counts. And snapshots of your project's files, including small files git ignores, such as .env, so a rewind can bring them back.
  • Where it keeps it. In ~/.zerostel on your computer (or the folder ZEROSTEL_DIR names), readable only by your user account. Your project's own .git is never touched.
  • What it sends. Nothing. There is no telemetry, no analytics, no account and no update check. The only server in the program is zerostel ui, which serves the timeline on 127.0.0.1 to your own browser, and only while you run it.
  • What you share. A report from zerostel report is a file you choose to give to someone. With --share it leaves out prompts, commands, output and diffs.
  • Deleting it. zerostel prune removes recordings older than 30 days by default, and deleting ~/.zerostel removes everything. zerostel uninstall takes Zerostel out of your agents.

Where you get it

Zerostel is published on npm, GitHub, the MCP Registry and Anthropic's plugin directory. Downloading or installing it from one of them is covered by that service's own privacy policy.

This website

zerostel.com is a set of static pages served by Cloudflare Pages. It sets no cookies and has no analytics and no third-party scripts or fonts. Cloudflare handles each request, including your IP address, to deliver the pages, under Cloudflare's privacy policy.
